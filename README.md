# Portfolio BUT Informatique — Marceau LE SECH

Portfolio interactif : un arbre gravé sur une colline, que l'on remonte en scrollant (racines, tronc, branches, feuillage, cime). Vite, Three.js, GSAP, Lenis.

```bash
npm install
npm run dev      # développement
npm run build    # production, dans dist/
```

Déploiement : GitHub Pages via `.github/workflows/deploy.yml` (réglage Pages : Source = GitHub Actions).
